# Support

## How to file issues and get help

This project uses [GitHub Issues](https://github.com/microsoft/sqlsimtools/issues) to track reproducible bugs and scoped feature requests. Please search existing issues before filing a new one to avoid duplicates.

For help and questions about using this project, please:

1. Read the per-tool documentation under `sqlsim/`, `sqlpysim/`, or `sqlsimstudio/`.
2. Search [Discussions](https://github.com/microsoft/sqlsimtools/discussions) and [closed issues](https://github.com/microsoft/sqlsimtools/issues?q=is%3Aissue+is%3Aclosed) to see whether the question has been answered.
3. Start a [Q&A discussion](https://github.com/microsoft/sqlsimtools/discussions/categories/q-a) for usage help.
4. Start an [Ideas discussion](https://github.com/microsoft/sqlsimtools/discussions/categories/ideas) for a new simulator, workload, or early design proposal.
5. Open a [Private Preview request](https://github.com/microsoft/sqlsimtools/issues/new?template=private-preview.yml) to ask for access to a Private Preview platform.

## Microsoft Support Policy

**sqlsimtools** is an open-source project, not an official Microsoft product.
It is provided as-is under the MIT license and is not covered by Microsoft
commercial support. Help is available only through the documentation, GitHub
Issues, and Discussions in this repository.
