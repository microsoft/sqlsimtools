Run your first workload

Start with Studio on Windows. No hosted service, no .NET install, and no telemetry sent elsewhere. Use a development or test database you have permission to load test.

1
Download and extract →Install Microsoft ODBC Driver 18. Download the Windows bundle, unblock the trusted ZIP in Properties, then extract it. Keep the folder structure intact.
2
Open Studio and connectDouble-click sqlsimstudio\sqlsimstudio.exe. In your browser, choose your SQL server, database, and authentication method.
3
Run, watch, and compare →Enter a query, start with a small thread and iteration count, and run it. Watch live progress and review results before increasing the load.
