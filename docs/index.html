From download to first result

No hosted service. No telemetry sent elsewhere. The tools run locally and connect directly to the SQL target you choose.

1
Install the prerequisite →ODBC Driver 18 for sqlsim and Studio; Python 3.10+ for sqlpysim.
2
Download one package →Choose the complete Windows bundle or an individual command-line tool.
3
Choose one of four paths →Studio, native ODBC, mssql-python, or the Workload Builder agent.
